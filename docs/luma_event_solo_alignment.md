# Luma Event Solo Alignment

## Event

**Gemini AI Hackathon @Google Japan**  
Date: June 27, 2026, 10:00-18:00 JST  
Venue: Google Japan - Shibuya  
Format: full-day hackathon, solo or teams up to 6, live demos at 16:30.

## Hard Requirements

1. The project must integrate Google Cloud products.
2. Live demo time is 2 minutes per team.
3. Judging criteria: Google Cloud usage, innovation, and completeness.
4. Team formation happens after the workshop; solo participation is allowed.

## Solo Strategy

SilverLink should be presented as a solo-safe build:

> I am participating solo, so I chose a narrow, safe, executable slice that one builder can finish and demo reliably.

The slice:

- one calm ambient orb
- one Gemini vision moment
- one Google Cloud voice moment
- one semantic event injection
- one family/pharmacist handoff memo
- one explicit safety boundary

This avoids a broad platform promise and makes the project look complete within the event's one-day constraints.

## Google Cloud Compliance

Current demo proof:

- **Gemini API**: multimodal medicine/document understanding and structured output.
- **Gemini reasoning prompts**: Observe-Reason-Decide flow for semantic ambient events.
- **Google Cloud Text-to-Speech / Chirp 3 HD**: warmer Japanese voice path when configured.
- **Structured output**: medicine card and family/pharmacist handoff summary.

Boundary:

- Cloud Run review deployment and backend-issued Gemini Live tokens are the next delivery track.
- Gemini Live is an experimental probe, not the guaranteed stage path.
- Matter/Thread hardware is mocked through semantic event tokens in this MVP.

## 2-Minute Live Demo Script

**0:00-0:15 - Category**

Say:

> SilverLink is not another senior app. It is Ambient Family Intelligence for aging societies.

Show: one calm orb.

**0:15-0:40 - Gemini Vision**

Tap **見る** and open the demo medicine image.

Say:

> Gemini reads what can be safely read and returns structured output.

Show: large-text medicine card.

**0:40-1:00 - Google Cloud Voice**

Trigger **温柔音声を試す** if configured.

Say:

> Voice quality matters here. A warm Japanese voice is part of trust, and the app has a fallback if the cloud voice is unavailable.

**1:00-1:25 - Semantic Event**

Long-press the orb, open **Scenario Injector**, and choose **服薬サインなし**.

Say:

> The proactive path sends semantic tokens, not raw sensor streams.

**1:25-1:45 - Human Handoff**

Show the **家族・薬剤師への交接メモ** and tap copy.

Say:

> The point is not an AI decision. The point is a human handoff.

**1:45-2:00 - Safety Close**

Point to the disclaimer.

Say:

> SilverLink does not diagnose or change dosage. Technology should not replace relationships. It should quietly protect them.

## Judging Checklist

Use of Google Cloud:

- Say "Gemini" and "Google Cloud Text-to-Speech" out loud.
- Show vision output and voice path within the first minute.

Innovation:

- Frame as Ambient Family Intelligence, not medication reminder.
- Emphasize silent signal detection and low-interruption care.

Completeness:

- Keep the live path short.
- Show fallback-ready features.
- End with a copied handoff memo, not just a screen.
